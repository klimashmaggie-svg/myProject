# Лендинг "Pure Beauty"

## Тема проекта
Сервис доставки нишевой косметики "Pure Beauty"

## Использованный CSS-фреймворк
Bulma

## Структура сайта (карта сайта)
- Хедер (логотип + навигация)
- Hero-секция (заголовок + кнопка)
- Преимущества (3 карточки)
- О проекте (текст + изображение)
- Рекомендуемые товары (3 карточки)
- Футер (контакты + соцсети)

## Исправленные ошибки (из анализа конкурентов)
- Добавлены alt-атрибуты ко всем изображениям (текстовые заглушки)
- Убраны запреты масштабирования в meta viewport
- Все кнопки имеют понятные названия
- Есть основная секция main (через div)
- Цвета контрастны и читаемы
